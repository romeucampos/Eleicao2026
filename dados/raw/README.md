# Boletins de urna brutos (TSE)

Este diretório contém 31 arquivos `.dat` originais, um por seção principal da zona 0213 em Águas Vermelhas/MG. Eles foram baixados do repositório oficial de dados do TSE e mantidos em seu formato ASN.1 binário. Cada arquivo é um boletim completo da seção; os auxiliares, a configuração, o schema e os cadastros EA20 dos cargos também ficam aqui para reprocessamento. Os CSVs processados ficam em `dados/`.

Os mesmos arquivos também estão preservados em `dados/boletins_aguas_vermelhas_2026.zip` junto com os auxiliares e o schema ASN.1 usados na extração.

Para Presidente, os BUs do 1º turno permanecem em `boletins/`; os BUs do 2º turno ficam em `boletins/2o_turno/`, com manifesto próprio em `boletins/2o_turno/manifesto_boletins_raw.csv`. Os arquivos correspondem às 31 seções principais de Águas Vermelhas/MG.
