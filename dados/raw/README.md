# Boletins de urna brutos (TSE)

Este diretório contém 31 arquivos `.dat` originais, um por seção principal da zona 0213 em Águas Vermelhas/MG. Eles foram baixados do repositório oficial de dados do TSE e mantidos em seu formato ASN.1 binário. Cada arquivo é um boletim completo da seção; os CSVs processados ficam em `dados/`.

Os mesmos arquivos também estão preservados em `dados/boletins_aguas_vermelhas_2026.zip` junto com os auxiliares e o schema ASN.1 usados na extração.
